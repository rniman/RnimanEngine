## 기준 시점과 달성 범위

주석 태그 `v0.1.0`은 2026-10-13 생성·이동했다. 최초 대상 `21d2a7a`에서 문서 정리를 포함한 커밋으로 이동했으며 최종 대상은 `git rev-parse "v0.1.0^{commit}"`으로 확인한다. 최종 태그의 실행 코드는 아래 재검증 대상과 같으며 당시 문서 정리 후 빌드·실행은 반복하지 않았다.

별도 BaseColor 에셋을 준비해 텍스처 큐브 3개·카메라·기본 Phong 조명을 문서대로 빌드·실행하는 기준을 충족했다. WIC·sRGB·깊이·Fence·리사이즈를 연결했으며 범용 장면·Transform 계층·ECS·Unity 로더·PBR은 당시 범위 밖이다.

## 주요 선택

창·입력은 Win32Window, 앱·카메라·조명은 SandboxApp, GPU 자원·동기화는 D3D12Renderer가 소유한다. 파일 디코딩과 GPU 업로드를 분리하고 두 프레임 슬롯은 Fence 완료 후 재사용한다. WARP 자동 대체는 없다. 왼손 View·Projection, 행 우선·행 벡터·HLSL row_major, World 역전치 법선을 사용한다. 현재 계약은 [Architecture](../design.md)를 따른다.

## 최초 태그 생성 후 재검증 (2026-10-13)

문서만 수정한 작업 트리에서 다음을 확인했다. 앞선 합성 입력·시각 확인과는 아래 날짜로 구분한다.

- x64 Debug·Release의 Sandbox·RendererSmoke·WindowSmoke·셰이더 빌드 성공. 샌드박스 안은 LNK1101(MSPDB140.DLL 버전 오류)로 실패했으며 샌드박스 밖 MSBuild로 통과했다.
- 두 구성 Smoke 종료 코드 0. CPU 변환·카메라·조명·PNG, GPU 텍스처·Phong·비균일 Scale/전단 법선·가림 통과. D3D12 오류/경고·잘못된 가림 픽셀 0.
- 실제 BaseColor의 Sandbox는 두 구성 모두 숨김 창으로 실행하고 WM_CLOSE로 정상 종료했다. 화면의 시각적 확인은 수행하지 않았다.
- 두 구성 CubeVS의 FXC dumpbin에서 세 행렬의 row_major·offset 0/64/128·각 64바이트를 CPU 선언과 대조했다. 행 간격은 16바이트, 상수 슬롯은 256바이트다.

## 당시 남은 검증과 제약

- CSO 누락/손상, 조명 입력 거부 모달, PSO·Signal·Present 강제 실패·장치 손실·전체 live-object·극단적 수치 정밀도·성능은 미검증이다. 자동 테스트의 오류 0은 전체 누수·성능 보장이 아니다.
- Normal/Roughness/AO/Height·DDS·압축·밉맵·캐시·텍스처 교체, 그림자·감쇠·다중 광원·PBR·HDR는 없다. 큐브 일부 잘림·축소 떨림이 남고 공면·교차 메시·투명도는 미검증이다.
- DPI·최소 창 크기는 미정이다. 모달 리사이즈 시 렌더링이 멈출 수 있고 Raw Input·커서 고정·충돌은 없다. VSync·Present 대기는 유지한다.

## 컨벤션 확인 기록 (2026-10-13)

10월 12일은 공개본 접근 실패로 로컬 `D:/Docs/Convention/docs/`의 baseline·C++ 채택 문서를 참고했다. GPU 캡처의 호출/실패 검사·인자 배치·include를 수정했고 나머지는 확인만 했다.

10월 13일은 공개 [baseline](https://rniman.github.io/convention/baseline/)·[좌표축/행렬 규칙](https://rniman.github.io/convention/coding/coordinates-and-matrices/)의 HTTP 200과 관련 내용을 확인했다. 기존 행 우선·행 벡터·전달 전치 없음이 일치해 문서에 정리했으며 코드 변경·새 시험 적용은 없었다. 로컬 정면·거리 단위·외부 에셋 변환, 비정방 행렬·배열 패킹은 도입 시 결정·검증한다.

당시 후속 후보는 일반 오브젝트·ECS 비교였으며 현재 순서는 [로드맵](../roadmap.md)에서 관리한다.
