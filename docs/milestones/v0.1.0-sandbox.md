## 기준 시점과 달성 범위

- Git 주석 태그: `v0.1.0`. 대상 커밋은 `git rev-parse "v0.1.0^{commit}"`으로 확인한다.
- 태그 생성·이동일: 2026-10-13. 최초 대상 `21d2a7a`에서 문서 정리 커밋으로 이동했다. 이 마일스톤 문서와 Architecture·개발 안내 정리가 태그에 포함된다.
- 2026-10-13 재검증은 최초 태그 생성 후 문서만 수정한 작업 트리에서 수행했다. 최종 태그의 실행 코드는 당시 검증 대상과 같으며, 문서 정리 후 빌드·실행을 추가 반복하지 않았다.
- 첫 마일스톤 기준: 직접 정의한 메시·텍스처·카메라·기본 조명을 사용하는 데모를 문서대로 빌드·실행한다. BaseColor 에셋은 별도로 준비한다.

위치·크기가 다른 텍스처 큐브 3개가 회전하며 카메라와 방향광을 조절한다. WIC PNG 로딩·sRGB·깊이 가림·Phong 조명·프레임 Fence 동기화와 리사이즈를 연결했다. 범용 장면·Transform 계층·ECS·Unity 로더·PBR은 이 범위에 포함하지 않는다.

## 주요 선택

- 창·입력은 Win32Window, 앱 흐름·카메라·조명은 SandboxApp, GPU 자원·동기화는 D3D12Renderer가 소유한다.
- 파일 디코딩과 GPU 업로드를 분리하고, 두 프레임 슬롯을 Fence 완료 후 재사용한다. WARP로 자동 대체하지 않는다.
- 왼손 View·Projection, 행 우선 저장·행 벡터 연산, HLSL row_major를 사용한다. 법선은 World 역전치로 변환한다.
- 단일 PNG·고정 큐브·방향광 하나로 실제 실행 흐름을 먼저 완성했다. 상세한 현재 계약은 [Architecture](../design.md)를 따른다.

## 최초 태그 생성 후 재검증 (2026-10-13)

**2026-10-13 첫 마일스톤 재검증:** 문서 재배치만 변경했으며, 메시·텍스처·카메라·기본 조명 데모의 빌드·실행 재현을 확인했다.

- x64 Debug·Release의 Sandbox·RendererSmoke·WindowSmoke·셰이더 빌드 성공.
- 두 구성 RendererSmoke·WindowSmoke 종료 코드 0. CPU 변환·카메라·조명·PNG와 GPU 텍스처·Phong·비균일 Scale/전단 법선·가림 검사를 통과했다. 각 136프레임·8회 리사이즈, 잘못된 가림 픽셀 0·D3D12 오류/경고 0.
- 실제 BaseColor를 사용하는 Sandbox 두 구성을 숨김 실행 후 WM_CLOSE로 종료하여 종료 코드 0 확인. 숨김 창에 대한 CloseMainWindow 호출은 실패해 프로세스별 창 열거·WM_CLOSE로 종료했다.
- 두 구성 CubeVS의 FXC dumpbin으로 행렬 패킹·offset·크기를 CPU 선언과 대조했다. 문서의 로컬 링크·좌표계 이전 앵커와 diff를 확인했다.
- 샌드박스 안 빌드는 LNK1101(MSPDB140.DLL 버전 오류)로 실패했다. 샌드박스 밖 MSBuild에서는 두 구성 모두 성공했다.

앞선 합성 입력·GPU readback 시각 결과는 아래 2026-10-12 기록이며 이번 실행 결과와 구분한다. 첫 마일스톤은 현재 에셋 준비 조건에서 데모의 빌드·실행 재현 달성을 뜻하며, 기능 제약은 아래에 유지한다.

## 당시 남은 검증과 제약

- 최신 CSO 누락/손상, 조명 입력 거부의 모달 진단, PSO·Signal·Present 강제 실패·장치 손실·전체 live-object·극단적 수치 정밀도·성능은 미검증이다. 오류·경고 0은 자동 테스트 범위이며 전체 누수·성능 보장이 아니다.
- Normal/Roughness/AO/Height·DDS·압축·밉맵·캐시·텍스처 교체, 그림자·감쇠·다중 광원·PBR·HDR는 없다. 상단 큐브 일부 잘림·단일 밉 축소 떨림이 남으며 공면·교차 메시·투명도는 검증하지 않았다.
- DPI·최소 창 크기는 미결정이다. 모달 리사이즈 중 렌더링이 멈출 수 있고 물체 잘림을 자동 보정하지 않는다. Raw Input·커서 고정·충돌은 없으며 VSync·Present 대기는 유지한다.

2026-10-12 문서 정리에서는 파일 형식·저장소 로컬 링크/앵커 68개·로컬 위키에서 연결한 앵커 6개와 diff 검사를 통과했다. 빌드·실행·시각 검증은 반복하지 않았다.

## 컨벤션 확인 기록 (2026-10-13)

2026-10-12에는 로컬 위키의 baseline·C++ 9개 채택 문서를 참고했다. 공개 위키와 로컬 Git 조회가 실패해 당시 공개본·메타데이터 일치는 확인하지 못했다. GPU 캡처의 호출/실패 검사 분리·여러 줄 인자 배치·불필요 include 제거를 실제 수정했고 나머지 규칙은 확인만 했다.

2026-10-13 공개 위키의 [적용 기준](https://rniman.github.io/convention/baseline/)과 [좌표축·행렬 채택 규칙](https://rniman.github.io/convention/coding/coordinates-and-matrices/)을 HTTP 200 응답으로 확인했다. 최초 웹 조회 도구·샌드박스 DNS 조회 실패 시 로컬 `D:/Docs/Convention/docs/`를 임시 참고했으며, 이후 샌드박스 밖 HTTP 조회로 공개본의 관련 채택 범위·전달 규칙·검증 기준을 재확인했다. 기존 Transform·카메라·RenderData·CubeVS의 구현을 확인해 설계 문서에 정리했으며 코드 변경·새로운 시험 적용·성능 예외는 없다. 로컬 정면·거리 단위·외부 에셋 변환은 실제 에셋 사용 흐름이 생길 때 계약을 정한다. 공통화할 새 코드 후보는 없다.

기존 코드의 행 우선·행 벡터·추가 전달 전치 없음은 채택 규칙과 일치한다. Debug·Release CubeVS의 FXC dumpbin에서 세 행렬의 row_major·offset 0/64/128·각 64바이트를 CPU의 192바이트 구조체·offset 검사와 대조했다. 행렬의 행 간격은 16바이트이며 오브젝트 상수 슬롯은 256바이트다. 법선의 3×3은 셰이더 내부 캐스트이고 Constant Buffer에는 4×4로 전달한다. 비정방 행렬·행렬 배열은 현재 없으며 도입 시 별도 패킹 검증이 필요하다. 재실행 결과는 [태그 이후 재검증](#최초-태그-생성-후-재검증-2026-10-13)를 따른다.

## 문서 재배치 (2026-10-13)

개발 설정·검증 방법은 development, 구현 계약은 Architecture, 날짜별 결과는 이 문서로 분리했다. 저장소 문서와 로컬 메모의 링크·앵커 97개 및 diff 검사를 통과했다. 이 재배치에서는 코드가 바뀌지 않아 빌드·실행·시각 검증을 추가 반복하지 않았다. 위 재검증 결과는 같은 날 앞선 실행 기록이다.
