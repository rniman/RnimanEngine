# 완료된 마일스톤 기록

[프로젝트 소개](../../README.md) · [로드맵](../roadmap.md) · [개발 설정과 검증](../development.md)

완료된 범위·검증·당시 제약을 기록한다. 진행 중인 계획은 docs/plans에서 관리한다.

| 기록 | Git 태그 | 달성·재검증일 | 범위 |
|---|---|---|---|
| [Sandbox 기본 렌더링](v0.1.0-sandbox.md) | `v0.1.0` | 2026-10-13 | 메시·텍스처·카메라·기본 조명 데모의 빌드·실행 재현 |

완료 시 `<tag>-<주제>.md`에 대상 커밋·달성 기준·검증일·제약을 기록한다. 태그가 없으면 `m02-<주제>.md`처럼 단계 이름을 쓰고 미태깅으로 표시한다. 재검증·정정은 날짜·대상·변경 여부를 추가해 기존 결과와 구분하며 태그를 자동 이동하지 않는다.
