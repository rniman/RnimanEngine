# 완료된 마일스톤 기록

[프로젝트 소개](../../README.md) · [로드맵](../roadmap.md) · [개발 설정과 검증 방법](../development.md)

완료된 마일스톤의 달성 범위·주요 선택·검증 결과·당시 제약을 기록한다. 예정·진행 중인 범위와 완료 기준은 [로드맵](../roadmap.md)과 `docs/plans/`의 계획 문서에서 관리한다. 현재 구현 계약은 Architecture, 실행 방법은 프로젝트 README에서 관리한다.

| 기록 | Git 태그 | 달성·재검증일 | 범위 |
|---|---|---|---|
| [Sandbox 기본 렌더링](v0.1.0-sandbox.md) | `v0.1.0` | 2026-10-13 | 메시·텍스처·카메라·기본 조명 데모의 빌드·실행 재현 |

마일스톤이 완료되면 `<tag>-<주제>.md`로 달성 기록을 추가하고 태그 대상 커밋·달성 기준·검증일·남은 제약을 기록한다. 완료했지만 태그가 없으면 `m02-<주제>.md`처럼 단계 이름을 사용하고 미태깅 상태를 표시한다. 계획만 수립했거나 구현 중인 항목은 이 목록에 추가하지 않는다.

이전 기록은 당시 상태로 유지한다. 나중에 재검증하거나 오류를 정정하면 날짜·대상 커밋·변경 여부를 별도 절에 남긴다. 새 결과를 과거 태그의 검증 결과로 덮어쓰거나 태그를 자동 이동하지 않는다.
